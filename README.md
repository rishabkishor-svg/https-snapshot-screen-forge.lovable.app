## 1. Problem Overview
Connecting AI agents to third-party tools requires developers to register and configure OAuth 2.0 applications. However, this workflow introduces unpredictable friction:
- **Opaque approval timelines:** Ranging from 5 minutes (GitHub) to 4+ weeks (Google restricted scopes).
- **Hidden verification requirements:** Domain ownership, unlisted video demonstrations, third-party security audits (CASA), and privacy policies.
- **Fragmented developer portals:** Inconsistent terminology for scopes, redirect URIs, and manifest schemas across providers.

**OAuth Compass** solves this by offering instant setup roadmaps, friction grading, and a clear division between what an agent can automate versus mandatory human checkpoints.

## 3. Standardized Guide Schema
Every setup guide generated by the engine surfaces 5 critical dimensions:
1. **Friction & Effort Score:** Quantitative estimates of setup duration and external approval wait times.
2. **Prerequisites Checklist:** Mandatory account tiers, domain ownership, and policy assets.
3. **Actionable Walkthrough:** Console direct paths, redirect URI configuration, and granular tool-calling scopes.
4. **Approval Blockers:** Specific hurdles that trigger application rejections.
5. **Agent vs. Human Boundary:** 
   - **Autonomous Agent:** Manifest synthesis, redirect URI validation, least-privilege scope selection.
   - **Human Oversight:** 2FA authentication, enterprise legal agreements, billing activation, identity verification.

## 4. Evidence & Grounding Evaluation
- **Verified Steps:** Core OAuth 2.0 authorization code flows, standardized scope naming, and developer portal URLs were cross-referenced with official documentation.
- **Agent Uncertainty & Known Limitations:** 
  - Dynamic console UI shifts (providers frequently redesign administrative settings).
  - Gated enterprise portals (e.g., Salesforce, SAP) cannot be fully inspected by public web agents without active paid instances.
  - Granular marketplace compliance rules change frequently without deprecation notices.
